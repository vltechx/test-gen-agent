# test-gen-agent-console

A web console for the test-generation agents in this repo, modeled on a cloud console:
a sidebar shell, a runs table with filters, a run detail page and an agent comparison.

## Live demo

https://test-gen-agent-one.vercel.app

- **Runs** and **Instances** show sample data.
- **Part Analyzer** calls the live API on AWS Lambda (`part-analyzer-api/`). Its quotes are fake.

**Status: sample data.** The agents don't save their results yet, so `public/api/runs.json`
is generated by `scripts/make-sample-data.py`. The next step is to have each agent write
the same JSON shape (`src/api/types.ts`) after every run.

## Stack

| Concern | Choice |
|---|---|
| Build | Vite |
| UI | React 19 + TypeScript |
| Routing | React Router (layout route + `<Outlet />`) |
| Server state | TanStack Query (one cached `['runs']` query; `select` derives a single run) |
| URL state | Filters in search params (`?agent=...&outcome=...&q=...`) |
| Styling | CSS Modules + CSS variables |
| Hosting | Vercel (`vercel.json` rewrites routes to `index.html`) |

## Run it

```sh
cd console
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + production build
```

Regenerate the sample data: `python3 scripts/make-sample-data.py`

## Layout

```
src/
  api/          types, fetch + query hooks, stats, formatting
  components/   Shell (sidebar layout), PageHeader, StatusChip, Stat, QueryState
  pages/        Home, Runs, RunDetail, Agents, NotFound
  router.tsx    route table
  main.tsx      QueryClient + RouterProvider
```
